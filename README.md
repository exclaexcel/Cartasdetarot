# Oraculo LuzComAromas

Web app mistico em Next.js 14 para uma experiencia comercial e visual de tarot, cristais e bem-estar.

## Stack

- Next.js 14 com App Router
- React 18
- Tailwind CSS
- Lucide React
- TypeScript

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` para ver a home.

## Rotas iniciais

- `/` - Home comercial com hero, CTAs e secoes de conversao.
- `/cristais` - Catalogo elegante de cristais e propriedades.
- `/tarot` - Interface visual para tiragem intuitiva de tres cartas.
